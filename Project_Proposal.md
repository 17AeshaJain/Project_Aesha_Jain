Problem Statement:
The Real Problem We're Tackling :
•	In this busy world, everyone knows fitness matters—especially students and young adults juggling classes, jobs, and life—but starting a routine feels overwhelming.
•	Beginners hit roadblocks like scattered information online, confusing apps that demand subscriptions, or workouts that assume you're already a pro.
•	Students especially struggle with tight schedules, no coach on hand, and basics like "What's my BMI?" or "What exercises fit my goals with/without a gym?"
•	Current sites overload with advanced plans and ads, leaving newbies lost, confused and demotivated.
•	We need a simple, one-stop web spot that's fun, mobile-friendly, and packed with straightforward guidance to spark real habit change.
Target Audience:
The Primary Target Audience For This Project Includes:
•	College students and young adults
•	Beginners who want to start a fitness routine
•	Individuals seeking basic fitness and wellness guidance
•	Users looking for simple fitness assessment tools such as BMI calculation
The website is designed to be easy to use, visually appealing, and accessible, making it suitable for users with little to no prior fitness or technical knowledge.

Related Works:
Popular Fitness Platforms Out There:
•	Healthline, MyFitnessPal, Nike Training Club: Great for workouts, tracking calories, and pro-level plans with nutrition tips.
•	Common Downsides for Beginners:
1.	Heavy on advanced routines that scare off newbies.
2.	Need sign-ups, apps, or paid upgrades to unlock basics.
3.	Overloaded interfaces and content feel intimidating, not inviting.
How FitStart Stands Out:
•	Simplicity First: No logins, no paywalls—just pure, beginner-focused info on workouts, diet basics, and tools like BMI calc.
•	Core Focus: Interactive, responsive design nails essentials without overwhelming—perfect for students starting small.
•	Big Win: Proves web dev basics while delivering real value as a free, accessible alternative.
Expected Outcome (What We'll Deliver):
•	Live, Ready-to-Use Website: A fully responsive fitness hub hosted free on GitHub Pages—accessible anywhere, anytime.
•	Core Features for Beginners:
1.	Structured workout plans tailored for newbies.
2.	Simple diet and wellness tips to build healthy habits fast.
3.	Fun interactive tools: BMI calculator + smart contact form validation.
Technology Stack:
•	HTML5 – For semantic page structure (sections, navigation, forms).
•	CSS3 – For styling, layout, and responsive design.
•	JavaScript (ES6) – For BMI calculations, and form validation.
•	GitHub Pages – For deploying the final live website as mandated in the course guidelines.
